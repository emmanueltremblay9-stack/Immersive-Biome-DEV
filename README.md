# Immersive Biome — DEV

Dépôt public de développement du mod Minecraft **Immersive Biome** par **Dirty Studyo**.

**Cible technique héritée du prototype (à qualifier dans la base DEV) :** Minecraft Java 1.21.1, NeoForge 21.1.233, Java 21. La version du mod, son ID et son nom de package ne sont pas encore adoptés.

**Concept de travail :** simulation d'évolution régionale persistante et observable avec diversité historique, y compris quand les chunks ne sont pas chargés. Hors chunks, seul un **état abstrait** peut évoluer : aucune physique, entité, machine ou effet de monde simulé en l'absence du chunk.

**Exclusions du périmètre actuel :** CIVITAS, PNJ, RPG, Neural Core; Immersive Transcendence reste ON HOLD. Aucun effet de gameplay n'est déclaré implémenté ou validé ici.

La gouvernance et les décisions à qualifier sont conservées dans le dépôt privé `Immersive-Biome-GPT`; les vérifications et le code résident ici. Pas de licence de redistribution du code créée par ce README.

**État d'initialisation :** structure à installer sur branche de préparation; aucun build ni test NeoForge réel prouvé par ce dépôt.
